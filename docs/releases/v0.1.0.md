# MatterHarbor v0.1.0

MatterHarbor v0.1.0 completes the first fictional-data case-management slice and its release evidence. It remains an early-stage portfolio and learning project, not a production-ready service. Do not use it with real personal data.

## Supported scope

- Development personas and fail-closed production OIDC configuration.
- Organization-scoped case list, details, creation, and integer-versioned status updates.
- Idempotent case creation, immutable creation audit, transactional outbox, and local worker processing.
- PostgreSQL migrations and fictional development seed data.
- Health endpoints, fixed-window rate limiting, problem details, security headers, and OpenTelemetry instrumentation.
- React development UI with accessible loading, retryable error, and concurrency-conflict recovery states.
- Local Docker Compose dependencies, container definitions, un-deployed Bicep, and CI verification.

## Explicitly unsupported

Production operation, real personal data, role/assignment administration, full transition policy, comments, files, malware scanning, search, privacy lifecycle workflows, backup/restore, disaster recovery, and a service-level commitment are outside v0.1.0. Azure infrastructure remains an un-deployed design artifact.

## Verification highlights

Hosted HTTP integration tests cover authentication, tenant isolation, validation/problem responses, rate limits, and idempotency replay/conflicts. CI runs Playwright without skipped tests against the real API, worker, web, and PostgreSQL stack and verifies that the worker drains the created outbox message. Dependency vulnerability checks, three container builds, Compose validation, and Bicep compilation are release gates.

Build from the `v0.1.0` tag using the [reproducible build instructions](../development/reproducible-builds.md). Report vulnerabilities only through [GitHub private vulnerability reporting](https://github.com/ArinF1/MatterHarbor/security/advisories/new).
